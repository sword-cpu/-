# 信息科学基础课程知识网络系统

这是在第一步课程数据预处理项目基础上完善的第一部分系统原型。第一步的数据和 `preprocessing/clean_data.py` 保留；新增 Streamlit 浏览器界面，用于展示知识层级、分别展示三类知识关系、查询知识点、分析复杂网络结构，并浏览数据一致性问题。

## 在 PyCharm 中启动

1. 解压本项目，并用 PyCharm 打开包含 `app.py`、`data`、`preprocessing` 的项目根目录。
2. 在 PyCharm Terminal 确认当前目录是项目根目录，再运行：

   ```powershell
   python -m pip install -r requirements.txt
   python -m streamlit run app.py
   ```

3. 浏览器打开 Streamlit 显示的本机地址，通常是 `http://localhost:8501`。

如果提示缺少 `data/processed` 文件，可先运行：

```powershell
python preprocessing/clean_data.py
```

## 系统页面

- **系统总览**：查看知识点、层级、关系及数据异常概况。
- **课程知识体系**：按全课程或课程模块查看层级树；点击节点逐层展开或收起，显示父子归属。
- **知识关系网络**：分别查看层级、先修、关联网络；先修和层级关系显示方向，关联关系按无向关系展示。可搜索节点并查看两层邻域。
- **复杂网络分析**：比较三类关系网络的密度、连通分量、孤立点和平均度；查看节点度分布、度中心性、中介中心性及关键节点局部结构，并导出结果。
- **知识点查询**：查看层级属性、教学目标、知识说明及相邻关系。
- **数据一致性检查**：筛选、查看并下载同名、关系目标缺失或歧义、先修环等技术核查记录。

## 模型说明

本系统按教师提供的课程知识点表构建节点、层级关系、先修关系和关联关系。三类关系分别展示和计算网络指标，避免将不同语义的关系混合解释。数据一致性页面单独呈现源表转换过程中发现的技术问题。学习路径评价和链路预测不属于本阶段功能。

## 主要技术

Python、pandas、NetworkX、Streamlit、Apache ECharts。系统以课程表和第一步生成的 CSV/JSON 为数据源，不需要单独配置图数据库。
